## Maintaining documentation

Use lowercase ASCII names with hyphens for new primary guides. Put English guides
in `docs/` and Chinese copies in `docs/zh-CN/`. Standard root documents (README,
CONTRIBUTING, AGENTS) stay at the root. Link both languages and register the pair
in `docs/catalog.json`. Update both in the same PR when behavior or commands
change. The English CLI command catalog is generated by `tools/generate_cli_docs.py`;
the Chinese guide retains operational explanations. Do not label an untranslated
document as an English copy. Update links, build/script references, and the catalog
when moving a document. Run `python tools/check.py --check docs --check cli-docs`
to check local links, language pairs, and CLI reference freshness.

Keep illustrations in `docs/assets/`, research records in `docs/research/`, generated
reports/PDFs/logs in ignored `artifacts/`, and release packages in `dist/`.
Application component directories remain at the root to match their native project
boundaries; native regression projects live under `tests/native/`, shared MSBuild
configuration under `build/msbuild/`, and support scripts under `scripts/`.
